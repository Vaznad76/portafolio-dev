# Mi Portafolio de Desarrollo Web

Bienvenido al repositorio de mi portafolio personal de desarrollo web. Este proyecto fue construido desde cero aplicando buenas prácticas de ingeniería de software y arquitectura web moderna.

## Tecnologías Utilizadas

- **HTML5:** Estructura semántica y accesible (SEO y lectores de pantalla).
- **CSS3:** Diseño responsivo (Mobile First), Box Model y Flexbox.
- **JavaScript (ES6+):** Manipulación dinámica del DOM, funciones flecha y renderizado dinámico de tarjetas a partir de datos estructurados.
- **Control de Versiones:** Git y GitHub.
